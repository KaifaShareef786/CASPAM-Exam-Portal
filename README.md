# CASPAM University Exam Portal

A responsive university practice examination portal using HTML, CSS and JavaScript.

## Project files
- `index.html` — website structure and pages
- `style.css` — layout, responsive design and background image styling
- `script.js` — live clock, countdown, timetable, MCQ exams, timer, scoring and explanations
- `assets/caspam-building.jpg` — the CASPAM building photo supplied for the background

## Run on your computer
Keep all files and the `assets` folder together. Open `index.html` in a modern browser.

## Publish using GitHub Pages
1. Extract the ZIP file.
2. Upload the contents of the project folder to the root of your GitHub repository. Do not upload only the ZIP.
3. Confirm that `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder are visible in the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to finish publishing.

## Important
This is a front-end demonstration. Student profile and result history are saved in the current browser using localStorage. There is no secure login, shared online database or admin panel. The timetable dates and MCQs are sample content; replace them with approved official information before real academic use.
